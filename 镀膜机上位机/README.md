# 直线模组上位机（张大头 Emm 固件）

控制张大头（ZDT）第二代闭环步进电机驱动的竖直直线模组，通过 **USB 转 RS485** 连接笔记本。

## 功能

- 图形化竖直滑块：顶部 0 mm，底部行程 39 mm，实时显示当前滑块位置与目标位置
- 界面右上角「高级」小开关控制是否显示高级内容：
  - **默认（精简）**：只显示连接、滑块、速度、上/下点动、归零、下止点设置、急停、解除堵转保护
  - **高级**：额外显示波特率/地址/校验、加速度档、丝杆导程、使能/失能、设零、停止回零、堵转保护电流与精度计算
- 输入丝杆导程（默认 2 mm），自动计算：
  - 脉冲/圈、位置精度（μm/脉冲）、编码分辨率、速度精度、最大线速度
- 连接后**自动读取电机参数**（细分、步距角、堵转保护电流等）
- 位置控制（移动到目标）、速度点动（按住上/下移动）、**急停**
- 使能/失能（锁轴/松轴）、设零、**向上碰撞回零**、**解除堵转保护**

## 安装与运行

```bash
# 用与运行时一致的 Python 安装依赖
python -m pip install -r requirements.txt

# 运行（Windows 也可直接双击「启动.bat」）
python main.py
```

依赖：`PySide6`（界面）、`pyserial`（串口）。

## Windows 运行与打包

**方式一：一键运行**
- 双击 `启动.bat` 即可运行（首次运行会自动创建 `.venv` 虚拟环境并安装 `PySide6` 与 `pyserial`）。

**方式二：打包成独立 `.exe`**
- 双击 `build_win.bat`（产出 `dist\LinearStage\LinearStage.exe` 目录版）或 `build_win_onefile.bat`（产出单文件 `dist\LinearStage.exe`）。

## macOS 运行与打包

代码完全跨平台，Mac 上同样可用。

**方式一：直接运行**
1. 安装 Python 3（<https://www.python.org/downloads/>）。
2. 双击 `mac启动.command` 即可（首次运行自动创建虚拟环境并安装依赖；若无执行权限可执行 `chmod +x mac启动.command`）。

**方式二：打包成独立 .app（分发用）**
- 在 Mac 上运行 `bash build_mac.sh`，产出 `dist/LinearStage.app`，可拖入「应用程序」，目标机器无需安装 Python。

**方式三：打包成单文件（最便携）**
- 在 Mac 上运行 `bash build_mac_onefile.sh`，产出 `dist/LinearStage`（单个可执行文件），双击即运行，可直接发给别人。
- 单文件每次启动需先解压到临时目录，启动比 .app 稍慢。

注意：
- USB 转 RS485 需装对应驱动（FTDI 或 CH340/CH341），串口在软件里显示为 `/dev/tty.usbserial-*` 或 `/dev/cu.*`。
- 打包出的 .app 未签名，首次打开若提示「无法验证开发者」：右键 .app → 打开，或终端执行 `xattr -cr dist/LinearStage.app`。
- PyInstaller 不能跨平台交叉编译，`.app` 必须在 Mac 上打包。

## 接线与设置

1. USB 转 RS485 接到分电板或电机驱动板的串口（A/B 对应），装好驱动后会出现一个串口（Windows 为 `COM*`，macOS 为 `/dev/cu.usbserial-*`，软件会自动识别 CH340/USB 串口）。
2. 打开软件 → 确认串口（默认波特率 115200、**默认地址 3**［对应分电板第 3 口覆膜仪电机，避开 X=1 / Z=2］、校验固定 0x6B）→ 点「连接」。
3. 连接成功后自动读取电机参数并**自动使能锁轴**（防止滑块因重力下滑）。

## 使用流程

1. **回零**：点「回零（向上）」——向上无限位碰撞回零，滑块顶到上端后自动归零（回零参数已在电机里配好，本软件不会改它）。
   - 回零过程中如需中断，点「停止回零」。
2. **设零**：也可手动点动到顶部后点「设零」，把当前位置当作 0 mm。
3. **移动**：输入目标位置（0~39 mm）和速度（mm/s），点「移动到目标」。
4. **点动**：按住「↑ 上移 / ↓ 下移」持续移动，松开即急停。
5. 堵转/过热/过流保护触发后，先排除问题，再点「解除堵转保护」恢复。

## 方向与参数约定

- 方向：**向上 = CCW，向下 = CW**（已按此映射，无需反转）。
- 细分默认 **256**（1.8° 电机，51200 脉冲/圈），连接后自动读取覆盖。
- 速度命令单位为 RPM（0~6000），软件按导程换算成 mm/s 显示：`mm/s = RPM × 导程 / 60`。
- 位置按编码器多圈计数换算：`mm = 计数 × 导程 / 65536`（65536 = 1 圈）。

## 文件说明

| 文件 | 作用 |
|------|------|
| `main.py` | 主界面 |
| `motor.py` | 电机控制线程（串口收发、轮询、命令队列） |
| `emm_protocol.py` | 协议常量、校验、机械换算 |
| `stage_widget.py` | 滑块可视化控件 |

协议依据 ZDT_X42S / ZDT_Y42 用户手册及开源库 [xhfb/emm_stepper](https://github.com/xhfb/emm_stepper)。

## 注意事项

- 运行前先「回零」或「设零」，否则显示的位置是编码器累计值，不一定对应 0~39 mm。
- 若滑块方向相反，请检查 A/B 接线；软件内方向约定见上。
- 竖直模组务必保持使能（锁轴），否则滑块可能因重力滑落。
