# 三种实验模式、任意路径与进度

## 日常操作

页面顶部选择“实验模式”，修改后点击“应用执行设置”。成功保存有勾选和路径 / 轮数反馈；新编辑撤销成功标记、旧预览与实物确认。正在运行或标定时不可修改执行设置。

| 模式 | 需要填写 | 实际含义 |
| --- | --- | --- |
| 一次性实验 | 勾选物理列 | 按列号升序各访问一次 |
| 重复实验 | 勾选物理列、总轮数 | 完整路径执行 N 轮，不是额外再做 N 轮 |
| 自定义路径 | 有序列序列 | 按原顺序执行一次，允许反向、跳列及重复访问 |

例如勾选 1、3、5、7、9 并设三轮，会执行 `1→3→5→7→9→1→3→5→7→9→1→3→5→7→9`。最后停在第 9 列安全高度，不再返回第一列。

自定义路径可填 `1,3,5,7,9,7,5,4,3,1`。单数字列也支持 `13579` 简写；单独输入 `10`、`11`、`12` 表示该物理列，访问两次第一列应明确写 `1,1`。涉及多位列号建议始终用逗号，例如 `1,3,10,12`。0 不是列号，`1357924680` 会被拒绝，若想最后去第 10 列，应写 `1,3,5,7,9,2,4,6,8,10`。保存反馈显示正规化路径供核对，不根据 0 猜测实物位置。

自定义路径显式应用时只勾选其中出现的列，不删除或改写其余列参数。每次访问均沿用该列已有名称、采集时长、A–H 有效窗口，以及全局采样电位 / 量程、上下 / 横移速度与停稳等待。已有各列 5 秒不会被模式切换改成 180 秒；若未来需要不同列不同时长，仍在该列参数中修改。

每次访问都先抬安全 Z、横移、浸入、停稳、等待 START 确认、采集、停止输出、提出。连续两次同列也会完整提出再浸入，分别保存数据。轮间返回同样先抬高，不在液体中横移。暂停仍在当前访问完成并提出后生效；停止仍是主动停止，不会自动返回或自动重启。

## 顶部进度

全宽进度条显示总百分比、当前轮次、路径位置、当前物理列、已用时间及预计剩余时间。数值来自实际运行的计划和反馈，不从当前编辑区推算。

剩余估计包含有序横移、升降、停稳、采集和轮间返回；真实运行初始估计使用已读当前位置。驱动加速、通信和设备连接开销使其只能是预计值。尚未收到当前访问 START 确认，不虚增采集进度。暂停、等待人工或设备恢复时，预计时间挂起而不假倒数；停止 / 故障不会显示已完成 100%。

## Agent 文档

在现有完整模板副本上设置 schema 与 execution，仍调用 `/api/automation/v1/guided/experiment`、`guided/preview`、`guided/run`。不要用以下片段代替完整模板。

```json
{"schema_version":"guided-1.1","execution":{"mode":"repeat","count":3,"route":null}}
```

`route:null` 使用已勾选列的物理顺序；`once` 的 count 必须为 1，`repeat` 为整数 1–500。自定义模式：

```json
{"schema_version":"guided-1.1","execution":{"mode":"custom","count":1,"route":[9,3,3,12,1]}}
```

数组只接受 1–12 整数，不能用字符串、浮点、布尔、0 或禁用列；保留顺序和重复。`custom` 的 count 必须为 1。旧 `guided-1.0` 不带 execution，继续按原意执行一次。

服务端编译为动作 schema 1.1，其中可选 execution 的 route 已解析为实际数组。新增扩展必须与完整访问动作流一致，不能把同一次浸入的两次 dwell 冒充两次访问。mode / count / route 都进入计划指纹，旧哈希不能启动新路径。

每次访问有唯一动作号、目录和指纹。新扩展样本包含 `cycle_index`、`path_index`、`visit_index`，均从 1 起；visit_index 为累计访问号。同一物理列在多轮或同一路径中出现多次，不会覆盖或混为同一次采样。manifest 保存执行策略、访问列表与最终进度。

GET `state` 的 progress 字段：percent、completed_steps、total_steps、completed_visits、total_visits、cycle_index、total_cycles、path_index、path_length、elapsed_s、remaining_s、estimated_finish_unix_s、suspended、route、mode。等待或故障情况下剩余时间可为 null；历史记录无本次进度对象时界面明确显示暂无进度。

## 保护与验收边界

保留 500 个展开动作、八小时单次预算；路径或轮数超限会拒绝，不会截断执行。保留同连接四点、全计划 / 每段反馈检查、正常到位不多发 FE、未知 STOP 资源保留、板输出未知时横移阻断。不新增无限循环、自动回零或跨断电恢复。

自动实验接近记录的四点端点时采用[保守末段靠近](ENDPOINT-APPROACH.md)：预备点之后最后至多 1 mm 以 ≤0.5 mm/s 接近，初始安全高度走廊也限速。原目标、保护容差与键盘速度不变；运行中的时间估计包含限速。

离线串口替身、HTTP 模拟和 GUI 验证证据在 `artifacts/guided-routes-20261024/`。模拟验证不等于自定义 / 三轮双轴双板实物全流程验收。本轮不自动执行真实路径，也不修改硬件或固件。
