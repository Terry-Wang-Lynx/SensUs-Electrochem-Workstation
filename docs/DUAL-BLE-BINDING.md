# 双蓝牙连接与 A/B 绑定

## 普通页面

「高通量自动化实验 → 板卡与电极对应」提供蓝牙扫描、两块板选择、保存绑定、连接已绑定板和逐板断开。

- 板 A / 前板（远离 Z 轴电机）：CH1–4 对应电极 A–D。
- 板 B / 后板（靠近 Z 轴电机）：CH1–4 对应电极 E–H。
- 前后是用户指定的装配位置，不根据广播名、信号强度或发现顺序自动判断。下拉选项展示名称和完整系统蓝牙地址 / UUID；同名板仍可区分。
- A/B 不可绑定同一个地址；交换两板是一次原子保存。未使用的槽位可留空。
- 保存只修改两板地址，不覆盖采样参数、模板或滑台标定。刷新网页保留绑定，但不会自动连接或启动采集。
- 主页面的“单板测量目标”仍只能选择一块，这是普通测量/分析的目标，不是蓝牙连接数量限制。选择第二块不会断开第一块。

## 连接与采集所有权

后台为不同地址分别保持待机 BLE 会话；连接只读 INFO、STATUS，不发 START、STOP 或配置命令。某块连接失败不关闭其他板。状态来自实际连接健康检查，而不是过去扫描到过。

实物采集继续使用各板独立采集进程。在启动某板的采集器之前，后台仅释放该地址的待机会话；采集器接管连接，避免两个客户端同时占用同一块板。采集期间以采集器的已确认状态为准，不把待机释放误显示成正在采集的板断线。采集结束后不会虚构待机连接仍存在，可点击连接重新建立待机连接。

活动采集、参数写入或未确认的板卡停止会阻止连接/解绑等管理操作。仅滑台键盘标定不占用蓝牙板管理接口。普通连接按钮不是电极输出停止按钮；断开蓝牙不保证板端停止采样。

## Agent API

前缀 `/api/automation/v1/`：

| 方法与路径 | 请求 | 用途 |
| --- | --- | --- |
| GET `boards` | 无 | 缓存设备、待机连接、采集器状态、已保存绑定、忙状态；不操作硬件 |
| POST `boards/scan` | `{}` | 显式扫描 |
| POST `boards/bind` | `{"addresses":{"A":"UUID-1","B":"UUID-2"}}` | 原子保存 A/B 地址，空串为未绑定 |
| POST `boards/connect` | `{"addresses":["UUID-1","UUID-2"]}` | 保持独立连接；仅 INFO/STATUS |
| POST `boards/disconnect` | `{"addresses":["UUID-1"]}` | 仅断开所列待机会话 |

连接操作返回 `errors`，以地址为键。HTTP 200 不等于所有板都成功，调用方须检查该字段和各板 `connections`。不回滚已成功连接的另一块板。

普通设备列表另提供 POST `/api/devices/ble/connect`、`/api/devices/ble/disconnect`，请求为 `{"address":"UUID"}`；这两者不修改单板测量目标或 A/B 绑定。

绑定身份使用本机 BLE UUID / 地址，换电脑后须重新确认。物理插头到 MAX30134 CH1–4 的接线仍需逐路负载验收，不能把无线连接通过当作八路模拟精度通过。
