# SensUs 电化学工作站 0.5.7 预览版

本版在 0.5.6（A–H 八电极全套独立采样参数设置）基础上，针对长周期（40+ 轮）高通量耐久运行中暴露的 **闭环保持亚微米编码器微调误锁、重连/恢复后 RS485 退化为 6 帧分拆轮询及双轴刷新保鲜期边界** 进行了根因级修复。本地安装包为 Apple Silicon、macOS 14+ 自包含 DMG，内置 Python、蓝牙依赖及 OpenOCD，不依赖开发目录或外部虚拟环境。

## 0.5.7 新增与重点更新

- **长周期耐久运行与 RS485 遥测稳定性修复（0.5.7）**：
  - **放宽启动前静态脉冲锁定的亚微米抖动容差**：`install_experiment_calibration` 静态核验从 `> 1 count`（`0.03 µm`）统一为 `> _encoder_stability_counts`（`10.24 counts` / `0.31 µm`），消除闭环力矩保持下编码器微调触发的误报错自锁。
  - **重连 / 恢复 / 开跑前自动恢复 `0x43` 单帧高速遥测**：在 `recover_arrival` 与实物运行预检中自动核验并启用 `0x43` 单帧汇总遥测，防止串口重连或后端重启后退化为 6 帧分拆轮询模式。
  - **双轴 `refresh()` 保鲜期兜底补读**：在第二轴读取较慢导致第一轴样本超过 2 秒保鲜窗口时，自动对过期轴补读一次，消除双板 BLE 停采落盘高峰期的 `X feedback is unavailable` 误报。
  - **增强到位恢复（`recover-arrival`）兼容性**：支持对顶层 `calibration_motion` 故障（具备完整停止证据且无底层硬件故障码）直接执行原位核验恢复。
- **8 电极全套独立采样参数（A–H，含 0.5.6）**：
  - 高通量模板「采样参数（支持8电极独立设置）」面板提供 **全板默认基底 + A–H 八张独立电极参数卡片**。
  - 每根电极均可独立设置（留空或选“跟随默认”即继承全板默认值）：
    1. **测试电位 WE−RE (V)**（`−0.4` 至 `+0.4 V`）
    2. **WE 电位 (V)**（`0.25` 至 `1.535 V`）
    3. **电流量程**（`50 nA / 100 nA / 250 nA / 500 nA / 1 µA / 2 µA`）
    4. **偏置电流**（`10nA / 20nA / 40nA / 80nA / 10% / 20% / 50% FSR`，随该电极实际量程实时换算 nA 值）
  - 每张电极卡片底部实时显示该电极最终生效的完整参数摘要；启动采集时按通道独立下发 `CONFIG <ch> <fsr_nA> <offset_code> 0 <we_dac> <re_dac> 0` 并逐通道核对 `STATUS` 硬件回读。
- **提拉与运动速度修复（含 0.5.5）**：
  - 移除 `motion_approach.py` 在首次安全高度接近（`startup=True`）时将 Z 轴上提速度截断至 `0.5 mm/s`（`15 RPM`）的限速；所有安全高度上提与列间提拉均直接按配置的 `ascend_speed_mm_s`（如 `40 mm/s`）全速执行。
  - 支持最高 `80 mm/s` 高速运动与键盘快动；优化 `>2 mm/s` 自动运动加减速曲线（`acc=232`）及 `>20 mm/s` 高速刹停时的 `0.25 mm` 闭环 PID 动态刹车裕量，消除高速直冲终点时的微过冲误报。
  - 放宽到位目标寄存器（`0x33`/`0x34`）量化核验预算，消除停稳后 `1.68 µm` 级量化尾差中断实验的问题，并提供一键「原位核验并恢复标定」。
- **RS485 串口自动探测与无感切换**：
  - 自动枚举并匹配 CH340（`1A86:7523`）等 USB–RS485 串口，通过只读握手核验 X=1、Z=2 双轴身份；更换 USB 插口后无需手动进入高级设置重新选口。
- **双板 BLE 并发与通道映射统一**：
  - 支持 `pa-v52-a` / `pa-v52-b` 双板并发连接与重连恢复，统一从左到右电极通道映射（`A–D` → 板 A `[CH1, CH3, CH4, CH2]`，`E–H` → 板 B `[CH1, CH3, CH4, CH2]`）。
- **高通量界面交互重构**：
  - **统一时长设置**：顶部「全板每列默认时长 (s)」修改时自动同步所有未单独覆盖列，并新增「同步到全部12列」一键按钮；右侧面板精简为单列独立微调，默认折叠 8 路电极子窗口高级项。
  - **消除草稿死锁**：移除跨分区编辑时的 `FIELDS_NOT_APPLIED` 报错拦截，保存模板或启动前自动汇总应用各子面板修改。
  - **未就绪原因浮窗**：「开始实物实验」按钮不可点时，在工具栏下方直接展示黄色提示浮窗，逐条列出未就绪原因并提供一键修复按钮（一键勾选确认、一键保存、一键原位恢复标定、一键连接板卡）。
- **跨平台稳定性**：
  - 修复 Windows 文件句柄占用导致的保存锁冲突与串口/BLE 瞬态超时重连问题。

## 新功能（自 0.5.x 系列）

- **V5.2 蓝牙**：扫描、协议验证、独立多板连接，四路电流同时显示与保存，温度/电压监测；板型和通道标定身份隔离。
- **双板绑定与八电极**：前板 A（远离 Z 电机）对应 A–D，后板 B（靠近 Z 电机）对应 E–H；用系统蓝牙身份绑定，不按广播名、信号强度或连接顺序猜测。
- **高通量模板**：物理 1–12 列和 A–H 电极任意勾选，自由列名、全板默认时长、本列覆盖、独立通道采集窗口及八电极独立/共用采样参数。
- **三种有限实验模式**：一次性、勾选列重复N轮、自定义有序路径；允许折返和同列回访，各次访问独立记录轮次/路径位置/指纹。模式切换保留逐列参数，显式保存有勾选反馈。
- **顶部全程进度**：总体百分比、轮次、当前路径位置、已用及预估剩余时间；等待START、暂停或恢复时不伪造进度，停止/故障不显示完成100%。
- **一次连接四点标定**：物理第 1 / 12 列 X、浸入工作 Z、提出安全 Z；采点按钮显示已记录，完成或失败有明确反馈。每次重新连接须重新标定，不将旧上电的编码器数值当成绝对坐标。
- **键盘对位**：仅标定时开放 WASD、方向键和按住箭头，可调速度及上限，松键/失焦/切页/停止撤销输入；滚动有限目标不再因固定累计距离中断。
- **交互模型与设备状态**：采用整机 CAD 派生模型，X 只移动孔板托盘，Z 带动悬臂、电极及双板；新鲜编码器反馈优先，失效则明确显示位置未知。独立显示 RS485、X/Z 和板 A/B 状态。
- **Agent 接口与溯源**：结构化动作 JSON、计划预览、幂等运行、统一启停、逐样本设备/通道/时间/动作日志、原始数据及 SHA-256 溯源；掉线缺失留空，只续采本列剩余时间。

## 安装与运行

打开 `SensUs-Workstation-macOS-arm64-0.5.7.dmg`，把 `SensUs Workstation.app` 拖入“应用程序”。本包采用临时签名，没有 Apple Developer ID 公证；首次打开可能需要按 macOS 提示允许打开。蓝牙采集需开启系统蓝牙并授予应用蓝牙权限。

高通量实物流程：绑定两块板 → 连接 RS485 → 显式进入键盘标定并读取四点 → 完成标定 → 确认运动及电气策略 → 选择“实物实验”运行。断电、重连或参考身份改变后不要沿用旧标定。完成停在末列上方安全高度，不自动返回。

## 验证与限制

- 主机回归、真实控制器对象/模拟串口联调、源包检查和冻结后端冒烟验证随本版执行；详细验收边界见仓库文档。
- 单板 V5.2 蓝牙、双板同时待机连接和双轴基础运动分别做过实物验证；**双板双轴完整自动实验尚未通过最终实物验收**，不能把离线回放或安装包构建通过当成整机签核。
- 端点修正仅做约2.001mm单向受限检查、末段约1.343µm误差；原约199mm高速横移尚未修正后全程复验。详见[端点策略与边界](ENDPOINT-APPROACH.md)。
- V5.2 仅开放恒电位 I-t，不支持 CV/EIS/OTA；悬空测试中 CH3 曾出现模拟异常，四路模拟精度仍需逐路负载验证。
- 两块板不是硬件同步；SHA-256 是溯源指纹，不是已实现的电化学特征算法。
- 电机位置计数不能假设断电持久；3D 工作姿态仍含名义 CAD 假设，不代表碰撞安全或外部定位精度已验收。软件停止与窗口保护不能替代硬件限位、急停和现场余量。
- 此次本地交付验证针对 macOS Apple Silicon；不据此宣称 Windows 新功能或 Intel Mac 已实测。

下载文件的 SHA-256 见同一 Release 的 `SHA256SUMS.txt`。安装包不含用户测量数据、历史标定、蓝牙绑定或本机运行日志。
