本版本同时提供 Windows 和 macOS 分发包，内置上位机后端、稳定固件、OpenOCD、USB 更新工具及所需 Python 运行环境。完整上位机、V4/V5.1 固件、板定义、测试和打包源码随本次标签公开，版本与移交说明见 `docs/HANDOFF.md`。

## 本版本修复（真机联调抓到；除注明外 macOS 同样受影响）

**点「开始测量」/「用选中点生成测试曲线」要等十几到二十几秒。** 后台设备发现轮在整轮探测期间持有 `operation_lock`，所有用户操作排在它后面。现场实测 Windows 18.4–24.2 s、macOS 中位 4.1 s / 最大 13.8 s；重复点击会攒成一串请求，锁一放开一起返回。用户操作现在会抢占发现轮（取消机制原本就有，只是普通操作没用上）。

**Windows 上 USB 板一直显示不可用。** J-Link 枚举子进程超时后异常逃出，把设备发现线程每 25 秒打死一次，设备列表永远走不完 —— 而那台机器根本没插 J-Link。该枚举现在失败即等价于“没找到 J-Link”，超时从 25 s 降到 6 s，枚举改服务端过滤。

**工作区不能选在系统盘以外。** `D:\`、`C:\data\`、网络盘一律被拒（macOS 无此限制）。现在任意绝对路径可用，原有相对锚点优先级不变、旧记录仍可读。

**一个坏字节让整个工作区不可用**（`'utf-8' codec can't decode bytes ...`）。中文 Windows 上部分 CSV 曾按系统编码落盘；读取端现在按 UTF-8 → GBK → 替换三级回退，并在界面提示该文件建议重新导出。⚠️ 这类文件通过共享盘/导入带到 macOS 上同样会触发，所以两端都需要本版本。

**更新器可能在安装新版本时被打断**（macOS）。解 DMG 的系统工具输出按 locale 严格解码，遇到非法字节即抛异常。

## 本版本改进

- **标定图每点独立配色**：候选标定点用冷色系圆点、测试点用暖色系菱形，图下方两张表格的行内色块与图上颜色严格一致；同一浓度叠点用底色细边和尺寸差保持可见。超过 5 个点的降级为中性灰 + 表格序号。
- **失败请求与等锁现在留痕**：新增 `api.request.rejected`（被拒的 POST 一律记录，此前 409 完全不留痕）与 `api.lock_wait_slow`（等锁超过 500 ms）。诊断包里可直接区分“后端慢”“等锁”“前端卡”。

## 安装

- **Windows 10/11 x64**：完整解压 ZIP 后运行 `SensUsBackend.exe`。首次启动可能出现 SmartScreen“未知发布者”提示；首次使用未安装兼容驱动的 J-Link 时，在右上角“选择设备”中点击“准备 J-Link”并确认管理员权限提示。
- **macOS 14+ / Apple Silicon**：打开 DMG 后拖入“应用程序”。当前构建无 Apple Developer ID 公证，首次启动请在 Finder 中右键应用并选择“打开”。
- **连接映射**：V4 用 J-Link/RTT；V5.1 用 USB DATA/SMP。V5.1 空片首次引导或恢复仍需 J-Link/SWD；检测到多个设备时可手动选择。
- **升级**：0.4.15 及以后的版本可直接自动更新。**0.4.14 及更早的安装必须手动下载替换一次** —— 自动更新所依赖的证书修复本身在 0.4.15 里。

## 已知限制

- 界面上「请求超时，设备正在重新连接」是所有 API 超时的统一文案，与设备连接状态无关，本版本未改。
- 曾有一次界面无响应约 10 分钟（macOS），机制仍未证实；本版本新增的两个留痕事件正是为下次复发时定性用的。
- CI 已验证主机测试、冻结入口、包完整性与随包工具。本次 Windows 侧做了真机联调（V5.1 / USB，一轮 30 秒采集通过）；macOS 侧未接板复测。
