## 停止与限幅

- 仅高通量标定面板可见、窗口有焦点、存在当前键盘会话时响应WASD/方向键。输入框、选择框、可编辑文字、输入法组合及Ctrl/Alt/Meta组合键不触发；系统按键repeat不重复启动。
- 松键、指针松开/取消、失焦、页面隐藏/关闭、切页、收起面板、采点/完成/取消/速度设置都会请求停止；Escape和“停止”也停止。
- 客户端100ms心跳，后台单调时钟350ms租约；迟到心跳、已松开按键的晚到start响应、旧会话、重复请求均不能复活旧移动。取消ID只保留到会话结束，达到数量上限拒绝新输入，不淘汰后复活。
- 不使用无限持续的F6。精调每条FD相对当前位置短段最多0.1mm、名义0.12s；快移使用有界6mm滚动目标，最多一条事务在途，无未确认排队。当前按住不再受固定30秒/10mm上限限制，仍遵守本次会话的名义行程范围。
- 每段运动前后复核双轴反馈、完整profile及非运动轴保持位置。FD执行期间只轮询活动轴；到位/0RPM之外，还需至少200ms的编码器安静窗口，之后向活动轴发送一条有ACK的FE，再做双轴复核。不是运动中持续监测另一轴；任一复核失败、超时或未知STOP均封锁后续段。
- 普通事务之间保留20ms总线静默；手册仅说明命令之间应延时几毫秒，20ms是本次保守调试选择，不是厂方通用保证或已证明的EE唯一根因。显式安全STOP不等待可选间隔，正常段末FE仍遵守间隔；等待后重新检查取消、原始期限与残留字节，不重试或吞掉EE。
- 松键发生在指令写出后时，先在原事务期限内收完并验证该帧回应，再交出串口发送STOP，避免STOP插进未完成回包。缺包仍按期限失败。快速换方向等待自有STOP完成；等待期间已松开的新按键不会延后运动。
- 非STOP静止判断允许不超过半个命令微步且不超过配置到位窗的编码器量化变化；实际非零RPM仍立即拒绝。STOP确认保持两次新鲜健康0RPM且计数差≤1，不放宽此标准。
- 日志回调在回应读取完成之后执行，保留原始收发时间；普通读数各命令保留独立超时，显式操作总期限不延长。反馈时间取读取开始的保守时间，超过2s则无效，不能把日志阻塞后的旧位置标成新数据。默认单段完整审核期限5s不增加FD位移，显式配置期限仍优先。
- 空闲实测捕获完整有效回应耗时627ms、超过旧300ms默认值；默认事务预算调整为1s，不修改调用方显式期限、350ms按键租约或2s反馈失效标准。键盘空闲反馈真正失败时，即使驱动已标为故障，也实际尝试双轴STOP并附带确认结果；不会因为“驱动已故障”而跳过停止，也不自动续动。
- 全局STOP与退出先撤销键盘输入，不等待普通操作锁；迟到请求不能在停止后再动。
- 进入时仅在两次目标33/34读取与当前编码器一致的容差内才允许锁轴；已锁定时只读确认，不额外F3。目标不一致不猜测重置方式。

这是普通电脑/串口的软件保护，不是安全认证急停。断线后无法保证驱动一定收到STOP，有限段仅限制已提交命令的位移；现场仍须留余量及硬件保护。

## 接口

均以`/api/automation/v1/`为前缀，GET只读缓存。只接受结构化操作，不接受原始指令、地址、计数或客户端时钟。

| 方法 | 路径 | 请求 |
| --- | --- | --- |
| POST | `guided/calibration/begin` | `{control_mode:"keyboard",motion_confirmed:true}` |
| GET | `guided/calibration/jog` | 当前会话、按键状态、设置与停止证据 |
| POST | `guided/calibration/jog/start` | `{session_token,press_id,axis:"X"或"Z",direction:"left"或"right"或"up"或"down"}`，轴与方向须匹配 |
| POST | `guided/calibration/jog/heartbeat` | `{session_token,press_id,sequence}`，递增整数≥1 |
| POST | `guided/calibration/jog/stop` | `{session_token,press_id}`，可先于start到达而取消该按键 |
| POST | `guided/calibration/jog/config` | `{session_token,speed_mm_s,max_speed_mm_s}` |

四点capture/finish/cancel沿用现接口。会话token由后端生成；每次按键创建新press_id，重复start幂等，不堆积。stop优先于普通操作锁；未知停止保留资源所有权并要求明确恢复，不能靠新Begin清除。
