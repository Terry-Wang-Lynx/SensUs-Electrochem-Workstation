# 高级运动参数的应用反馈

“应用高级参数”原先仅将表单写入前端模型，直到保存模板或开始实验时才写后台，按钮也没有明确反馈。现改为立即提交并等待后台返回完整一致的文档，再显示成功。

- 保存中：按钮禁用并显示“应用中…”，附近状态区域使用 `role=status`。
- 保存确认：绿色“✓ 已应用”，显示“已保存，下一次实验生效”及横移、提拉、下降速度、停稳等待和默认采集时长摘要。
- 再次修改：勾选状态撤销，显示“待应用”；保存途中发生编辑、切页或停止，也不能将旧请求的成功冒充新草稿已保存。
- 保存失败、响应缺少确认或参数无效：明确显示失败，保留草稿并阻止使用未应用表单开始实验。
- 默认时长不覆盖任何单列 `duration_s` 或通道窗口；摘要明确“单列覆盖优先”。设备绑定也不会被旧前端地址覆盖。

DOM 回归覆盖异步保存、成功/失败、完整响应核对、编辑与取消竞态、默认时长有效/无效输入和单列覆盖保持。实物开始的 Z 初始位置检查另见 `CALIBRATION-COMPLETION-POSE.md`；参数保存成功并不代表硬件标定或停止检查已通过。
