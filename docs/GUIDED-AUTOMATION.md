# 高通量实验：模板与手动标定

**2026-10-24 新增三种有限模式与顶部进度**：一次性、重复 N 轮、自定义路径；第三种不是无限循环。只需给列顺序，其余沿用已保存的逐列时长、采样窗口和统一运动参数。操作与 Agent 字段见 [路径与进度](GUIDED-ROUTES.md)。旧 `guided-1.0` 继续兼容；显式应用执行设置才升级 `guided-1.1`，不会把现有 5 秒改回 180 秒。

**最新操作改为[键盘四点标定](KEYBOARD-ALIGNMENT.md)**：每次开机先进入，WASD/方向键在该模式内对位，保持锁轴，不再手拧。目标速度和上限可设，松键/失焦/租约过期停止；读同样四点，完成后禁用键盘并走自动化。下方松轴步骤是同日较早实现的历史。

**2026-10-23最新流程**：普通页已改为[同次上电四点标定](POWERED-FOUR-POINT-CALIBRATION.md)，分别读取物理1列X、12列X、独立工作Z与安全Z；取消额外机械四极限/CAD配准。开始须显式松轴与Z支撑确认，保持供电；完成先验证目标寄存器再允许锁轴，失败保留受阻。下文2026-10-22三点与释放前阻断是历史实现，不代表当前普通页。

本页记录2026-10-22本地开发实现及离线验收。开发验证未操作实物，运动默认值不是新的碰撞安全签核。

## 普通流程

1. 选择需要的物理列1–12和电极A–H；跳列不压缩孔板坐标，取消电极不改变其余通道身份。
2. 使用“每列180秒”模板，需要时改列名、列时长和各通道有效采集时长。列名可直接写“10微摩尔每升”，不强制输入数值浓度。
3. 默认复用保存的标定；只有点击“标定”才进入流程。标定使用物理第1与第12列，不使用本次选中范围的两端。
4. 先预览模拟，再显式选择实物运行。端口、双板身份、轻柔运动速度、稳定等待、采集延迟和动作JSON放在高级设置。

全部电极共用Z轴，所以浸泡时长相同；各通道可以只取本列中的一段有效采集窗口。未选电极和窗口外数据不作为有效采集结果；原始数据与原因日志仍应保留。主机窗口不等于固件对单路电极按秒独立断电。

### 采样参数与时长

普通模板区新增“采样参数（8电极共用）”与“板卡与电极对应”两个默认收起的小tab。共用参数沿用V5.2实时测量的测试电位（WE−RE）、WE电位、采样周期、量程和偏置；点击“应用到两块板”仅修改模板的两板设置，保存后待实物运行时才下发。两板原有参数不同会显示提示，不在查看时悄悄覆盖。BLE身份、分析通道及其它参数不随五项共用设置改变。

180秒是模板默认值；本列覆盖框留空时继承模板。有本列覆盖值时，例如12秒，则本列实际时长为12秒，各电极的窗口都必须完整包含在这12秒内。窗口时长留空且延迟为零会删除覆盖，随后改变本列或模板时长能继续正确继承，不把旧时长冻结为一个自定义窗口。验收时曾给第2/7列设置12秒，这不是另一个全局采样时钟。

### 板卡、芯片通道与电极

| 绑定槽位 | 芯片/帧通道 | 固定电极身份 |
| --- | --- | --- |
| 板A（独立BLE地址/OS UUID） | CH1、CH2、CH3、CH4 | A、B、C、D |
| 板B（另一BLE地址/OS UUID） | CH1、CH2、CH3、CH4 | E、F、G、H |

不是按两个同名`pA-V5.2`广播、到包先后或“本次第几个勾选”分配身份。MAX30134 FIFO的DC标签0–3由板端解码为通道0–3，固件发送 `D,sequence,uptime_ms,channel,counts,current_fa,flags` 时转为1–4；主机校验通道1–4及本次mask后，用连接所属板槽位＋帧通道号映射A–H。每条样本同时保存板地址、槽位、通道、电极身份、重试身份、板端序号、时间及溯源指纹。

现固件`INFO`验证协议/MAX型号与四路能力，但没有上报MCU硬件唯一序列号。macOS返回的UUID是该操作系统的设备标识，不当作跨电脑的永久硬件序列号。哪个物理夹具接到了哪个芯片输入仍需要逐路已知负载验收；软件不能识别人为插错线。本轮离线测试刻意重排两板的CH4/1/3/2到包顺序，验证八路身份仍按通道号正确分配。

### 蓝牙连接提示

左下角在BLE模式区分“蓝牙尚未扫描”“正在扫描蓝牙”“扫描失败/权限问题”“未发现采集板”“上次扫描发现几块”。提示开启系统蓝牙，再从右上角“选择设备 → 扫描蓝牙”主动扫描；普通状态查询不会触发无线扫描。扫描候选数不等于当前连接数，协议验证也不等于双板联合验收。不读取到系统电源状态时，不谎称已经检测到蓝牙开关为开/关。

## 标定与机械边界

真实自动化运动还须先完成独立[四边界绝对运行限位](ABSOLUTE-MOTION-LIMITS.md)。它不由孔板标定、实验JSON或CAD行程代替；未标定/重连失效仍可模拟，但不能启动真实滑台运动。

首点记录物理第1列X与统一工作Z；末点记录物理第12列X；另记录安全抬升Z。X步距为 `(X12-X1)/11`，支持相反方向。两点Z差不用于倾斜补偿。

标定数据不是机械回零。配置/参考基准已知不一致时拒绝实物运行，保留原标定等待用户主动处理，不自动移动或重新标定。不同实验勾选和溶液标签不要求重新标定。

**手拧后原位锁定尚未实物验证。** 已检查的Emm手册没有保证重新使能不会回到失能前目标，也没有已核的无运动目标重置命令。软件不能拿普通使能、零脉冲位置指令或回零冒充原位锁定。因此真实驱动须在释放电机前阻断未经验证的手动标定；完整流程先由明确支持该能力的测试替身验证。后续需要单独确认锁定策略，不能把离线通过当作实物标定可用。

## 时间、缺失与停止

- 电极到工作高度并稳定后，至少一块所需采集板成功接受START才开始本列计时；记录主机请求、ACK和板端时间，两板不是硬件同步。
- 掉线只重连该板，健康板继续。180秒列在第100秒重连，只采剩余80秒；不延长本列，不补零、不插值、不把旧数据当新数据。
- 双板都掉线，本列仍按原时钟结束，然后抬安全高度等待恢复。下一列未START成功不倒计时。
- 不可达板的输出记为未知，不伪称STOP已确认。安全抬升不代表电气输出已关闭；未知输出未处理时，后续横移受安全门禁约束。
- 正常暂停在本列完成并抬起后生效；完成后停在最后实际执行列上方安全高度，不自动返回首列。
- 滑台通信、位置、存储审计故障仍按安全停止处理，不当作可忽略的BLE掉线。

## Agent入口

API前缀仍为 `/api/automation/v1`。普通模板使用独立的 `guided-1.0` 文档；服务端根据自身保存的标定编译为动作schema1.1，调用方不能自行注入可信标定。原始schema1.0动作程序继续保留。

| 方法 | 路径 | 内容 |
| --- | --- | --- |
| GET | `/guided` | 模板、保存标定及手动流程状态；无硬件动作 |
| POST | `/guided/experiment` | `{document}` 保存模板 |
| POST | `/guided/preview` | `{document,mode}` 校验并返回展开计划及哈希 |
| POST | `/guided/run` | `{document,mode,plan_hash,idempotency_key}` 运行匹配的计划 |
| POST | `/guided/calibration/begin` | 明确进入标定；驱动能力不足时先阻断 |
| POST | `/guided/calibration/capture` | `{point:"first"\|"last"\|"safe"}` 主动读点 |
| POST | `/guided/calibration/finish` | 验证并保存，不自动回原点 |
| POST | `/guided/calibration/cancel` | 退出流程，不恢复旧运动目标 |
| POST | `/pause`、`/resume` | 列末安全暂停、继续 |
| POST | `/stop` | 停止及输出恢复；无法确认则保留所有权 |

运行必须附匹配的计划哈希和唯一幂等键。接口沿用结构化错误 `{error:{code,message,path},request_id}`。溯源指纹是SHA256；电化学特征指纹算法尚未定义，不能混为一谈。

## 验收状态

证据目录：`artifacts/guided-validation-20261022/`。浏览器完成任意选列/电极、自由中文名称、参数保存、窗口越界阻断、列末抬起暂停/继续、默认继承与共用参数检查。API模拟仅执行物理第7列，选A/H，有48条原始记录、31条有效记录（A12/H19），最终停在该列X54/Z0；验证旧哈希与未标定实物被拒绝、幂等重试不重复运行、保存模板不受API临时实验影响，以及所有manifest文件SHA一致。前一轮浏览器第2/7列实验为288条原始、266条有效，暂停发生在第2列安全Z。

独立审阅发现并用回归修复STOP被参考恢复清除、停车checkpoint晚于STOP导致参考丢失、遗留重试采集进程未收到STOP、损坏标定记录引发启动异常、控制器/标定服务锁反转，以及长列重连32次后静默放弃。重连现在持续到固定列截止时间，退避上限8秒；600秒列在第300秒恢复可加入剩余窗口，健康板不重启。
