# Fast Keyboard Alignment Implementation Plan

**Goal:** 手动标定提供20 mm/s快移与0.5 mm/s精调，不只更改显示上限。

**Architecture:** ≤2 mm/s保留既有0.1mm有限精调。>2…20 mm/s使用Emm FD mode0（相对上一输入目标），一次按住内滚动续接位置；按手册§5.1.3可在运动中平滑更新。最多6mm已提交前瞻、单按仍最多10mm/30s，不用无限F6。仅开始/结束完整profile审核，运行中轮询活动轴并周期核查保持轴。默认保持低速，高速必须明确确认离孔及至少10mm余量。

**Global Constraints**
- 不改电机持久配置、零点、保护或使能状态，不做高速实物运动；现已确认的净空不足以验收20mm/s。
- 保留350ms租约、100ms心跳、取消后排空、严格双STOP、故障封锁与逐次目标读取取消修复。
- 当前两轴软件速度限值在明确请求20后改为20，自动流程默认运动条件不变，正式四点重新建立，不拼旧身份。
- 不建分支、不提交推送，不改硬件/固件。

**Review Focus**
- 有限6mm前瞻与制动/主机断连并非机械限位或安全急停。
- 开始时33目标与当前编码器有容差差异，量化必须向请求终点以内收敛。
- 未确认高速、轴上限低于20、速度低于一RPM不得提交FD。
- 松键发生在任意审核/ACK/遥测阶段仍只取消，不误包装为故障。
- 保持轴漂移、profile变化、EE/丢包必须停止且禁止自动继续。
