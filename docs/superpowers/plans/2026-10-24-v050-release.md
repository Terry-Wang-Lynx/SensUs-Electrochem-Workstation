# Workstation 0.5.0 Release Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Commit and push the accumulated workstation changes to the original repository, publish v0.5.0, and deliver a self-contained macOS DMG.

**Architecture:** Preserve the existing main checkout and release tooling. Validate source and frozen application independently; publish only verified artifacts from the release commit. Do not mix the sibling hardware repository into this release.

**Tech Stack:** Python, Swift/WebKit, PyInstaller, Git, GitHub Releases, hdiutil.

**Spec:** User request in this chat: all workstation code changes in the original Git repository, pushed, a new release and DMG.

## Global Constraints

- Original remote: `git@github.com:Terry-Wang-Lynx/SensUs-Electrochem-Workstation.git`; current version 0.5.0, latest released tag 0.4.16.
- Include all intended tracked and untracked source, tests, model assets, documentation and tooling; exclude ignored runtime state, measurements, secrets and local build products.
- DMG targets Apple Silicon/macOS 14+, bundles Python 3.12.10 and BLE dependencies; do not ship the development app with external venv paths.
- Do not move, enable, home, zero, program or sample physical hardware during release work. Hardware acceptance limitations remain explicit.
- No force push, history rewriting or deletion of user work. Only GPT-6.1 Sol delegated agents.

## Review Focus

- Frozen collection and BLE platform dependencies must work without the source checkout.
- Source archives must include JSON fixtures used by shipped tests.
- Release metadata, asset contents, commit/tag and checksums must agree.
- No stale calibration, active output or local acquisition data may become a shipped default.
- State actual signing, OS support and physical validation boundaries; do not claim Windows or full hardware acceptance without verification.
