# Continuous Keyboard Hold Implementation Plan

**Goal:** 用户按住对位时不再被固定10mm/30s上限中断，松键停止。

**Architecture:** 保留同一按键所有权、350ms续约、有限FD与6mm滚动待执行量。精调持续生成原有限段；快移单次调用持续滚动到松键/异常/现有会话名义行程边界，不在10mm处停稳重启。连续模式必须有取消信号；旧显式有界调用仍供诊断，不变成无限F6。

**Constraints:** 不改速度上限、松键/失焦/失联停止、停止证明、动态/停后包络或最终到位判据。名义会话行程不是机械限位，不假装已知未标定的物理终点。保留当前用户设置，更新元数据和文案。不提交、推送或实物长行程试验。

- [x] 先测试续约超过30s/10mm仍保持按住，连续快移大于10mm且每次待执行≤6mm，停止与会话边界仍有效。
- [x] 实现持续按住模式与元数据，去除经理层固定上限，更新UI说明。
- [x] 专项回归、独立复核；确认停止后更新正常服务，验证页面和当前设置，不新增实物运动。
