# 自定义路径、重复实验与全程进度

## 已明确的需求

2026-10-24 用户澄清：第三种模式不是无限循环，只需提供列顺序，例如 `1,3,5,7,9,7,5,4,3,1`，其余移动、上下速度、到位等待、采样及每孔时长按已有默认值执行。另需一次性实验、选定列重复 N 轮实验，以及顶部大进度条和预计剩余时间。不实现 infinite 模式，不改掉当前全部 12 列 5 秒的已保存设置。

## 三种模式

- 一次性：勾选列按物理列号升序执行一次，保持旧模板语义。
- 重复：勾选列按物理列号升序执行 N 轮，例如 `1,3,5,7,9` 三轮。只有还有下一轮时，末列抬高后返回路径首列；最终一轮结束只抬高，不返回。
- 自定义路径：有序、可重复的列序列执行一次，可从任意列开始，不排序、不去重、不压缩物理间距。

每次访问沿用该列名称、时长、A–H 有效窗口、采样参数及统一速度 / 停稳设置；连续同列也算独立采集。每次均完成安全抬升、横移、浸入、停稳、START、采样、STOP、提出，不增加逐动作编程负担。

## 文档及实现契约

- 旧 `guided-1.0` 文档不变，省略执行设置等价于一次性勾选列。
- 新 `guided-1.1` 必须带 `execution: {mode, count, route}`。mode 为 once / repeat / custom；count 为整数，once / custom 必须为 1，repeat 为 1–500；once / repeat 的 route 必须为 null，custom 为非空整数数组，每项 1–12，且必须为启用列。
- 界面支持单数字列连续简写，但单独的 10 / 11 / 12 表示相应物理列；访问两次第一列须写 1,1。多项且涉及 10–12 时用逗号分隔。0 不静默解释为 10，提示明确合法例子。显式应用自定义路径时同步勾选其中的列，不更改各列参数。
- `_translated` 仍输出动作 schema 1.1，新增可选 execution，字段同上，但 route 为实际顺序数组。使用既有 repeat 有限展开，保留 500 步与八小时完整计划 / 运行上限，超限提示而非截断。
- 编译器验证 execution 与实际访问顺序 / 轮次一致。新扩展计划每步带 `cycle_index`、`path_index`、`visit_index`，均从 1 起，visit_index 为累计访问号；重复访问的动作号、目录、样本指纹唯一。
- route / count / mode 纳入计划指纹。新编辑撤销旧预览与运行确认；保存接口和事件处理器均在忙时阻断，不热改运行计划。
- 原 guided-1.0、旧动作文档及既有计划哈希兼容；不修改自然到位无 FE、真实 STOP、标定身份或驱动协议。

## 进度契约

状态 progress 字段：`percent`、`completed_steps`、`total_steps`、`completed_visits`、`total_visits`、`cycle_index`、`total_cycles`、`path_index`、`path_length`、`elapsed_s`、`remaining_s`、`estimated_finish_unix_s`、`suspended`、`route`、`mode`。

顶部全宽大进度条来自已启动的不可变运行计划，显示总百分比、轮次、路径位置、当前物理列及预计剩余时间，不从编辑区反推。启动估计使用实际已读初始位置，后续包含有序移动、升降、停稳、采样及轮间返回，标明只是预估。

START ACK 之前不虚增采集完成量；暂停、等待人工 / 恢复时 remaining_s 和 estimated_finish_unix_s 为 null，显示等待而非假倒数。只在成功完成时显示 100%，停止 / 故障不能冒充完成。旧数据无 progress 时显示暂无本次进度。

## 安全及验收

保留本连接四点、全路径预检、每段双轴配置 / 反馈核验、安全抬高后横移、未知板输出门禁、列末抬起暂停、真实 STOP 所有权保留。重复展开包括末列到首列的返回。只读查看和保存不自动运动；重连不自动恢复旧标定或运行。

继续 Python / 原生 JS / CSS，不引入依赖、框架、硬件或固件改动。测试覆盖旧兼容、三轮、任意首列 / 折返 / 连续同列、非法输入 / 禁用列 / 超限、独立样本及目录、5 秒参数不变、轮间暂停 / STOP / ACK / ETA。HTTP 与浏览器仅模拟和读取，不自动实物试跑；部署前确认空闲停止并备份，新连接仍需重新四点标定。
