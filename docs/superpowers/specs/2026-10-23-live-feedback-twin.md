# 高通量设备状态与编码器反馈孪生

用户要求检查当前电机连接，并在左下角单列高通量设备；随后要求3D与真实电机位置对应，指出刚性连接可从电机位置确定整套姿态，手拧同样应跟随。

## 已核事实与边界

- 当前工作站已只读连通 `/dev/cu.usbserial-110`、115200，X1/Z2均0RPM/状态03，原始计数−5/1；没有发送使能/松轴/位移。变化由用户明确解释为手拧，不能仅因为计数改变就宣布基准失效。
- 保存的真实四边界记录当前为空；不能将“功能存在”说成“实测边界已保存”。
- CAD为刚性X托盘与Z悬臂/电极/双板两自由度；原始计数与对应CAD标量锚点已知后，可唯一计算整套位姿，不需要逐件标定。
- 源CAD模组是参考包络，没有实测机械止挡约束。X姿态参数是孔板中心，首/末列为+49.5/−49.5；Z是展示lift0…45，网格基准lift35、滑块中心132。150/50不能擅自当模型端点。
- 安全运行边界不自动等于CAD机械端点。四边界流程可同时记录各边界的CAD坐标，不增加实物搬动；缺此对应关系时明确未配准，不假装同步。不得按150/实测宽、99/实测宽或45/实测高拉伸模型。

## 实现

1. 独立左下角“高通量设备”：RS485、X1、Z2、板A/A–D、板B/E–H。分清已读通、反馈过期、故障、未绑定、仅绑定未验证、采集中/重连。通信正常不等于已标定或可运动，USB串口存在也不等于电机回包有效。
2. 显式连接后只读轮询已打开的总线，不自动找口/连接/使能/清零。真实运动/限位监测已拥有总线时使用其缓存，避免串口竞争；空闲时更新编码器反馈。GET仅取缓存，不打开物理设备。
3. 单独保存数字孪生配准，绑定当前已验证限位记录指纹、连接及CAD文件哈希。四个CAD对应值为X左/右的孔板中心坐标、Z上/下的模型lift，显式确认后才保存；计数从服务端限位记录取，不允许客户端注入真实计数。
4. 以机械导程/65536换算真实毫米，验证两端CAD跨度与编码器毫米跨度一致（默认显示配准容差0.1mm，不是安全停止容差），不缩放CAD。X取右界锚，Z取上界锚：`sceneX=XrightCAD−49.5−(rawX−rightCount)*leadX/65536`；`sceneZ=ZupLiftCAD−35−(rawZ−upCount)*leadZ/65536`。
5. 只有连接/profile/限位/CAD一致且两轴反馈新鲜时输出实时pose；断线、错误、过期或未配准输出未知状态，不用命令目标/计划位置补位。正常手拧及同连接普通STOP不使配准失效；已知基准/配置/连接变化则需核对。
6. 接上实物后真实反馈显示优先于模拟动画；鼠标相机仍可旋转。未知时允许查看明确标为参考的CAD姿态，不能称已同步。实时更新是带年龄/时间戳的编码器反馈，不承诺外部直线精度、零延时或视觉检测。

## API

GET `/api/automation/v1/devices`：缓存设备状态（motion/boards/limits）。
POST `/api/automation/v1/motion/refresh`：显式只读刷新已连接总线，忙于真实运动时仅返回缓存。
GET `/api/automation/v1/twin`：缓存反馈计算的state/pose/registration。
POST `/api/automation/v1/twin/register`：`{cad_bounds:{x_left_mm,x_right_mm,z_up_lift_mm,z_down_lift_mm},confirmed:true}`，服务端使用当前已激活限位记录；没有可注入计数或禁用运动限位的字段。

本轮不移动实物或代填边界/CAD锚点，不把演示值写成真实标定。原位重锁和绝对限位门禁保持。
