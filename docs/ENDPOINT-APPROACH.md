## 修正策略

记录的 X 首 / 末、Z 工作 / 安全端点高速接近时：

1. 目标与标定范围不变，不扩展原反馈或到位容差。
2. 如果距离足够，先用原请求速度到范围内预备点，再完成既有自然停稳、0 RPM、到位标志、目标寄存器及双轴配置复核。
3. 最后一段精确到原目标，指令速度不超过请求值及 0.5 mm/s。预备距离为至多 1 mm；窄范围用跨度四分之一，不能容纳脉冲 / 原容差余量时直接低速。阶段之间不发普通 FE。
4. 已在预备区或已到目标时，不先离开再返回；只做必要的低速有限运动或静止证明。
5. 初始 Z 安全高度接近若来自标定完成姿态的特殊走廊，仍只允许其原精确安全目标，采用一次低速有限接近，不扩大该走廊或绕过门禁。

两阶段在原非重入操作锁内，共享取消、STOP 代数、连接和标定身份、固定保持轴原始基线及整个操作截止时间；每段 FD 前后仍复核原完整配置。最终脉冲根据实读预备点重新计算并向范围内量化。中间到位不是逻辑动作完成，不冒充最终停泊证明；失败不重试 FD、不自动返回。

1 mm / 0.5 mm/s 是保守软件策略，并非已实测证明的全行程动态包络或安全保证。键盘对位不走此策略，WASD 速度不变。实际运行的剩余时间估计计入低速末段；通信 / 加速开销仍只作预估。
