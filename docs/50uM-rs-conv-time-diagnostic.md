# 50 µM 左旋多巴 RS / CONV_TIME 对照排查

## 目的

用单变量对照区分两种假设：

1. WE 模拟环路不稳定；
2. Sensor ADC 建立或积分时间不足。

测试使用同一片电极、同一杯 50 µM 左旋多巴溶液。共同条件为 +0.2 V、
120 s、2 µA FSR、50% offset。原始数据保留硬件时间戳、ADC counts、饱和标志和
每秒寄存器审计。

## 对照设计

| 记录 | RS | CONV_TIME | 原生周期 | 原生点数 |
|---|---:|---:|---:|---:|
| 原始问题曲线 `4-50uM` | 0 | 12 bit / code 0 | 124 ms | 968 |
| `DIAG-RS1-12bit-50uM` | 1（内部 60 kΩ） | 12 bit / code 0 | 124 ms | 968 |
| `DIAG-RS0-16bit-50uM` | 0 | 16 bit / code 4 | 476 ms | 253 |

16 位转换在 2 µA 快速量程下约需 471 ms，因此 SENS_PERIOD 必须从 code 0
同步改为 code 2（476 ms）；否则配置不满足 `conversion time <= sample period`。

## 结果

| 指标 | RS=0、12 bit（原始） | RS=1、12 bit | RS=0、16 bit |
|---|---:|---:|---:|
| 饱和原生点 | 30 | 8 | 0 |
| 10 s 后最大相邻变化 | 56.641 nA | **0.977 nA** | 48.737 nA |
| 10 s 后相邻变化 >20 nA | 7 次 | **0 次** | 9 次 |
| 最后 20 s 平均值 | -322.169 nA | -368.068 nA | -350.464 nA |
| 最后 20 s SD | 3.475 nA | **0.616 nA** | 1.364 nA |
| 台阶/振荡 | 存在 | **未出现** | **仍存在** |
| 电位/配置寄存器审计 | 通过 | 通过 | 通过 |

RS=1 曲线脱离启动饱和后连续、平滑地变化。10 s 以后没有一次相邻变化超过
1 nA，也没有原问题曲线中的台阶或周期振荡。

恢复 RS=0 并加长到 16 位后，18.246 s 至 22.555 s 仍出现成组往复跳变：

```text
-267.090 -> -315.826 nA  (-48.737 nA)
-315.826 -> -268.646 nA  (+47.180 nA)
-286.316 -> -330.078 nA  (-43.762 nA)
-287.354 -> -331.665 nA  (-44.312 nA)
```

该轮 253 个原生点序号连续，无 FIFO 溢出、异常 tag 或饱和。跳变期间以及全程的
寄存器审计均为 `target=200 mV`、`DACA=1067`、`DACB=533`、`S1_CONFIG2=0x90`
（RS=0）、`S1_CONFIG5=0x09`（16 bit）、`CONVERT_SETUP1=0x02`
（476 ms），未出现 `POTENTIAL_FAULT`。

## 判定

按预先给出的工程判据：

- RS=1 后台阶和振荡同时消失；
- 单独延长 ADC 积分时间后，台阶和振荡照旧。

因此本轮对照支持 **WE 模拟环路稳定性不足**，不支持“ADC 建立时间不足”作为主要
原因。-400 nA 不是量程或数字阈值；它是环路异常时经常经过的电流水平。

RS 会改变电流传递特性。本轮 RS=1 与 RS=0 的最后 20 s 平均值不能混入同一条
标定曲线。若把 RS=1 作为正式修复，必须把它纳入固定硬件协议并重新完成整套浓度
标定。单次顺序对照仍可能受电极随时间变化影响；正式定版前建议至少再做三组
RS=0/RS=1 交替重复。

## 排查中发现的软件问题

首次 16 位尝试发现，固件虽然用配置宏检查并打印 CONV_TIME/SENS_PERIOD，AFE
初始化表却把寄存器 `0x24` 和 `0x80` 硬编码成了 12 bit / 124 ms。该无效尝试只运行
约 31.6 s，已重命名为 `DIAG-RS0-16bit-attempt-invalid-50uM-raw.csv`，不参与上述
结论。

初始化现已改为直接使用配置宏，并把 S1_CONFIG2、S1_CONFIG5 和 CONVERT_SETUP1
加入采集中每秒回读审计，防止日志条件与真实硬件寄存器再次分离。
