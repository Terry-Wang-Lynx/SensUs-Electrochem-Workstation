SensUs Electrochem Workstation portable packages

The portable packages include a CPython runtime and open-source Python
dependencies. THIRD_PARTY_LICENSES/PYTHON_PACKAGES.json records the exact
versions installed in the release build, THIRD_PARTY_LICENSES/SBOM.spdx.json
contains the SPDX inventory, and the adjacent component directories contain
the license texts copied from those distributions. The CPython license is
included as Python-<version>/LICENSE.txt. The platform-specific portable lock
files pin every package version and accepted distribution SHA-256 hash used by
the release runners.

Both platforms include a J-Link-only OpenOCD 0.12.0 runtime built by this
project from pinned source. The only non-system native dependency is libusb
1.0.29. OpenOCD is distributed under GPL-2.0-or-later; libusb is distributed
under LGPL-2.1-or-later. Each tools/openocd directory contains:

- COMPONENTS.json with binary and source hashes;
- BINARY_DEPENDENCIES.txt with the audited native dependency list;
- licenses/ with the applicable license texts; and
- source/ with the complete corresponding OpenOCD and libusb source archives
  plus the exact build script used by this project.

OpenOCD's source archive includes the Jim Tcl and libjaylink sources used by
the build. The packaged runtime does not include Homebrew libraries, SEGGER's
proprietary J-Link software, FTDI, HIDAPI, Capstone, or MinGW runtime DLLs.

The Windows package also includes the wdi-simple utility built from the pinned
libwdi 1.5.1 source. It runs only after the user explicitly chooses "Prepare J-Link"
and approves Windows elevation. tools/winusb contains libwdi's LGPL/GPL terms
and source, the exact libusb-win32 and libusbK corresponding source archives,
their directly accessible license texts, Microsoft WDK License.rtf and
REDIST.TXT terms, the exact helper build script, and COMPONENTS.json with the
pinned binary, source, and input hashes.

The application may use a separately installed SEGGER J-Link Commander when
one is already present. That installation is selected only as a compatibility
fallback and is not modified or redistributed by SensUs.
